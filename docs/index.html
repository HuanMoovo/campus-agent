Mens 校园助手MENS CAMPUS ASSISTANT

把校园政策问答、知识库与办事服务放进一个本地优先的桌面应用

Mens 是一个面向院校场景的问答工作台：知识库文档（PDF / Markdown / TXT / Word）在本机检索， 校园服务（成绩、课表、学分、空教室、报修）通过可配置的 HTTPS 接口接入， 聊天支持流式回答、可停止生成、历史会话隔离，并可按需开启联网搜索引用网页来源。 文档、数据和密钥都留在本机，模型可接 Qwen3 / DeepSeek 云端 API，也可用 Ollama 跑本地模型。

版本 1.2.0 Windows 已构建并验收 macOS / Linux：CI 构建，未真机验收 Android / iOS：可安装网页版 本地 SQLite · 无需外部数据库

能做什么

以下功能均已在开发副本中实现并有验证记录，具体证据见仓库中的 VERIFICATION.md。

问答

流式回答与停止生成

逐字输出，可随时中断；已生成的内容会连同“已停止”标记一起保存，历史记录不会伪造完整答案。

检索

本地知识库

PDF、Markdown、TXT、Word (.docx) 上传后在数据库与（可选的）向量索引中检索；文档数据库是权威数据源，索引过期不会返回旧内容。

联网

可选的实时联网搜索

按每条消息开启。默认使用免密钥的 Bing 网页搜索（中国大陆可直连），也可配置 Tavily 或博查；网页结果带链接与检索时间，未启用时应用完全不联网检索。

服务

校园数据接口

九类校园 HTTPS JSON 接口可配置（成绩、课表、学分、空教室、报修等）。未配置时使用明确标注的演示数据，不会假装已接入学校系统。

模型

云端或本地模型

Qwen3 / DeepSeek 走各自的 API Key；本地模型由 Ollama 提供，内置模型下载支持断点续传与 SHA-256 校验。

桌面

单机运行的桌面应用

内置 Python 运行时，双击即用，无需另装 Python/Node/数据库。备份可导出为 zip，包含知识库、会话与配置（含密钥，需妥善保管）。

平台支持

“已验收”指在对应系统上真实安装、启动并完成界面检查；“CI 构建”指由 GitHub Actions 生成产物但尚未真机运行。

平台状态交付物与说明
Windows 10/11 x64 已构建并验收 NSIS 安装包，用户级安装（%LOCALAPPDATA%\Programs\Mens），数据在 %APPDATA%\CampusAgent
macOS 12+（Intel / Apple silicon） CI 构建，未真机验收 dmg + zip；未签名、未公证，首次打开需右键“打开”或在系统设置中允许

快速开始

Windows 安装包开箱即用；其他平台从源码构建，或使用网页版。

Windows：下载 Release 中的 Mens-Setup-<版本>-x64.exe，双击安装，从开始菜单或桌面启动。

从源码构建（三个平台同一脚本）：

# Windows
python scripts\build_desktop.py

# macOS（Intel 用 --arch x64）
python scripts/build_desktop.py --os mac --arch arm64

# Linux
python scripts/build_desktop.py --os linux --arch x64

从源码开发运行：

python scripts/install.py          # 安装依赖
# 后端（终端一）
start-backend.cmd                  # Windows；其他平台见 DESKTOP.md
# 前端（终端二）
start-frontend.cmd                 # 访问 http://localhost:5173

手机 / 平板：部署后端（见仓库 README 的服务器部署小节），手机浏览器打开站点后“添加到主屏幕”，即可获得全屏、独立图标的类应用体验。

架构与安全边界

技术栈

Vue 3 + TypeScript + Vite + Element Plus + Pinia 前端；FastAPI + SQLAlchemy + LangGraph 后端； Electron 外壳内置 PyInstaller 冻结的 CPython；SQLite 单文件数据库（可选 PostgreSQL）。

本机优先

后端只监听 127.0.0.1 的随机端口，使用一次性令牌；桌面外壳注入额外请求头，外部页面无法拿到这些接口。

出站请求约束

插件、联网搜索与更新检查只允许 HTTPS、固定到校验过的公网地址（保留 SNI，防 DNS 重绑定）、禁止跳转、有大小与超时上限；解析到内网地址直接拒绝。

密钥存储

Windows 用 DPAPI 加密保存 API Key；macOS / Linux 无等价系统接口，改为 0600 权限的明文文件（同一用户可读）。这一点在 PLATFORMS.md 中明确写出。

已知限制

以下内容尚未验证或尚未实现，如实列出。

  • macOS / Linux 产物未真机验收：由 CI 构建，尚未在真机上安装运行过。
  • 未签名、未公证：没有发行者证书，Windows/macOS 首次打开可能出现系统提示；正式分发前应配置签名。
  • 校园接口与统一登录：项目不附带任何真实学校接口、统一身份认证或模型密钥；生产部署需学校提供已授权接口并验收。
  • 云端模型与联网搜索：需要各自的 API Key（联网搜索的 Bing 通道免密钥）；搜索结果的服务端可用性受网络环境限制。
  • 原生 Android / iOS 应用：不在本项目范围，原因见 PLATFORMS.md（Python 后端无法随应用上架移动平台）。
  • 一键更新：更新检查只提示版本差异并打开下载页，不做自动下载与静默安装。
