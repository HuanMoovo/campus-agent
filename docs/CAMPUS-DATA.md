# Mens 校园数据接口

在“设置 → 校园数据接口”中按类型保存接口地址、JSON 结果路径和可选 Bearer 令牌。保存后立即生效。空令牌保留同一主机的已有令牌，更换主机时旧令牌自动清除，需要重新输入。Windows 桌面版用当前用户的 DPAPI 加密令牌，页面只显示配置状态。

支持九类数据：成绩、课表、学分、空教室、报修、校园公告、图书馆、餐饮和校车。除报修使用 POST 外，其余使用 GET。未配置时成绩、课表、学分、空教室使用演示数据；公告等扩展类型显示空列表。已配置接口出错会明确报错，不会伪装成真实查询成功。

接口须为公网可解析的 HTTPS 地址，端口 443，禁止用户名密码和重定向。每次请求校验并固定公网 IP，TLS 仍校验原主机。内网 IP、仅校内 DNS 可达地址、数据库直连、CSV/XML 和统一登录网页不能直接填写；这类系统需由学校提供有授权的 HTTPS JSON 网关或额外适配器。响应上限 2 MB。

## 返回格式

列表接口可直接返回对象数组，或 `{"items":[...]}`。如果学校返回 `{"data":{"rows":[...]}}`，结果路径填写 `data.rows`。结果路径仅从 JSON 对象逐级选字段，不执行表达式。

| 类型 | 必需字段或结果 | 示例 |
| --- | --- | --- |
| 成绩 `grades` | 每行 `course` 字符串、`score` 非负数值或等级字符串；可选 `credits`、`semester` | `[{"course":"高等数学","score":92,"credits":4}]` |
| 课表 `schedule` | 每行 `course`、`weekday`、`time`、`room` 字符串 | `[{"course":"高等数学","weekday":"周一","time":"08:00-09:40","room":"A101"}]` |
| 学分 `credits` | 对象，`required` 和 `earned` 为非负有限数值 | `{"required":160,"earned":100}` |
| 空教室 `classrooms` | 每行 `building`、`room` 字符串，`seats` 非负整数；可选布尔 `available` | `[{"building":"教学楼A","room":"A101","seats":60,"available":true}]` |
| 公告/图书馆/餐饮/校车 | 对象数组；字段名按实际数据展示 | `[{"title":"图书馆开放时间","content":"08:00-22:00"}]` |
| 报修 `repairs` | JSON 对象；嵌套内容按返回结果展示 | `{"id":"R20260001","status":"已受理"}` |

空教室查询会在返回列表中筛选教学楼、座位数，并排除 `available:false` 的记录。接口额外字段可以展示，但不能覆盖 Mens 的真实/演示标记。

## 报修提交

“测试读取”不会调用报修接口。用户需在“校园服务 → 报修申请”填写并明确点击提交。POST 请求体为：

```json
{"location":"3号楼205室","issue":"照明灯无法正常开启","contact":"学校授权的联系信息"}
```

配置后数据发送至已保存的学校接口；未配置时仅在本机保存演示工单。真实学校业务还需要学校网关实现用户身份绑定、权限、幂等、审批或派工。Mens 当前桌面配置按本机用户保存，不替代学校统一身份认证。

## 模型和校园凭据

不要把访问令牌放入 URL 查询参数，使用独立 Bearer 令牌字段。API Key、校园令牌和原有 `.env` 不会打入安装包。升级继续保留 `%APPDATA%\CampusAgent`，其中包括 `campus-sources.json`、`model-providers.json`、数据库和历史记录。
